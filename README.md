# Task Management System

This repository contains a React single-page application for managing tasks (todos) with create, view, update, and delete features. The UI follows the Ocean Professional modern style guide with clean aesthetics, subtle shadows, rounded corners, accent highlights, smooth transitions, and subtle gradients.

- Frontend container: `react_js_frontend`
- Start the app: `cd react_js_frontend && npm install && npm start`
- No backend required; data is persisted via `localStorage`.

See `react_js_frontend/README.md` for more details.
